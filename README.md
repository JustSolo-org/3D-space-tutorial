# 3D Space Shooter — Unity

Unity 3D space shooter game built to learn core game development concepts — ship movement, weapon systems, enemy AI, particle effects, and UI — via a guided tutorial series, with custom features added on top.

Built by following [**Make a 3D Space Shooter in Unity**](https://www.youtube.com/playlist?list=PLHcOLPSLOK7PNvLAdnqicE_BeqoNH7Zwz) by **Midnite Oil Software LLC**, with commits made incrementally per feature — the commit history itself is a build log showing how the project was put together, module by module.

---

## 📌 About

This project covers the core building blocks of a 3D game in Unity:

- Player ship movement and controls
- Shooting / weapons systems
- Enemy ships with AI and collision avoidance
- Particle effects and visual polish
- Materials, lighting, and camera setup
- Music and sound effects
- UI (HUD, score, health, menus)

Built primarily as a learning project to strengthen my Unity + C# fundamentals, with some personal tweaks and additional features layered on top of the base tutorial (noted below).

## 📂 Project Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/your-repo.git
   ```
2. Make sure [Git LFS](https://git-lfs.com) is installed:
   ```bash
   git lfs install
   git lfs pull
   ```
3. Open the project folder in Unity Hub with a matching Unity version.
